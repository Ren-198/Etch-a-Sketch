# 🎨 Etch-a-Sketch Drawing App

A simple web-based Etch-a-Sketch project where users can draw by moving their mouse over a grid.

---

## 📌 What This Project Does

This project creates a grid of squares that change color when you hover over them. You can also change the size of the grid using a button.

---

## 💡 Why This Project Is Useful

This project helped me practice:
- JavaScript DOM manipulation
- Event listeners
- Basic user input handling
- Working with HTML and CSS together

It’s a good introduction to building interactive web pages without using frameworks.

---

## ⚙️ How to Run the Project

1. Download or clone the repository  
2. Open the folder  
3. Double-click `index.html` to open it in your browser  

No installation or extra tools are needed.

---

## 🕹️ How to Use

1. Click the **“Set Grid Size”** button  
2. Enter a number between 1 and 100  
3. Move your mouse over the grid to draw  
4. Each square will change to a random color when hovered over  

---

## 🧱 Languages Used

- HTML  
- CSS  
- JavaScript  

---

## 📂 Files in This Project

- `index.html` → structure of the page  
- `styles.css` → styling for the grid and button  
- `backend.js` → JavaScript logic for grid creation and coloring  

---

## ⚠️ Limitations

- No reset button (you have to reload the page)  
- Only works with a mouse (not touch-friendly)  
- Colors are random (no color selection)  

---

## 🔧 Possible Improvements

- Add a clear/reset button  
- Let users choose colors  
- Add different drawing modes (like eraser or shading)  
- Improve styling and layout
